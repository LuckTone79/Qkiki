# Yapp v1.38.6 일일 모델 카탈로그

- QStash가 한국시간 매일 오전 4시에 네 공급사의 모델 목록을 새로 확인합니다. 같은 날짜의 성공한 공급사는 재시도에서 건너뛰고, 일시적 장애는 기존 카탈로그를 유지합니다.
- 공식 요금과 텍스트 입출력 형식을 확인할 수 있는 신규 공용 모델을 선택기에 반영합니다. 장문 구간에서 요금이 높아지는 모델은 보수적으로 공식 상한 요율을 적용합니다. 신규 이미지·검색 기능은 검증 대기로 남습니다. 일일 확인은 과금형 생성 API를 호출하지 않습니다.
- 기존의 직접 선택을 보존합니다. 기본 모델 자동 전환은 같은 계열의 후속 모델과 실제 실행 기록을 기준으로 하며 관리자 설정을 우선합니다.
- 기존 Prisma 관리자 설정 저장소의 예약된 키를 사용합니다. 일반 시스템 설정 API에서는 동기화 레코드 조회와 수정을 차단합니다.
- 운영 배포에서 `scripts/setup-model-catalog-schedule.mjs`로 고정 일정 ID를 등록하고 확인합니다.
