# Yapp v1.38.7 이미지 모델 일일 갱신

- 기존 한국시간 오전 4시 동기화에서 운영 키가 지원하는 OpenAI, Google 및 xAI 이미지 모델을 수집합니다. Anthropic은 현재 연동한 API에서 이미지 생성 모델을 제공하지 않습니다.
- 공급사 공식 문서에서 지원 호출과 요청 크기·품질에 대한 요금을 확인한 모델을 이미지 선택기에 반영합니다. 요금, 출력 규격 또는 실행 경로가 불명확한 후보는 보류합니다.
- 견적에는 이미지 출력과 적용 가능한 텍스트 요금이 포함됩니다. 공급사가 사용량을 반환하면 결과 비용에 반영합니다. 이미지 작업은 기존 병렬 실행 엔진으로 전송합니다.
- 일반적인 신규 모델의 일일 공개에는 별도 배포나 생성 API 호출이 필요하지 않습니다. 새 호출 규격은 공급사 문서 및 어댑터 지원이 필요합니다.
